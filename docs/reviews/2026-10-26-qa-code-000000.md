## 二、缺陷与缺口（本轮新认定）

| # | 级别 | 条款 | 现象与证据 |
|---|---|---|---|
| D1 | **高（P0 功能面）** | AC-47、AC-48、§10.2、F09 | **回放控件缺失**。两个入口（"查看回放"/"回放过程"）均只触发 setInterval 自动重演（`wiring/index.ts:531-546`），播完即退出；页面无 播放/暂停/上一步/下一步 按钮、无进度条/slider（DOM 全查为空）、方向键无步进、无速度切换与三种回放视角。AC-47（前进 k 步状态=events[k-1] 指纹）与 AC-48（拖拽定位 300ms）无 UI 路径可执行。前三轮均未覆盖此点。§3.4 MVP 一句话验收的字面（"点回放看到每一步重演"）已满足，但 §10.2 控件集为 P0 明确要求 |
| D2 | 中 | §7.4、§13.2 | **autoSubmitOnSolved 死设置**。`settings.ts:37/57/137` 定义且默认 true，但全仓无消费方；实测 solved 后 1.6s 仍停在 solved_pending，需手动"提交解答"。PRD 默认"人类模式自动提交"未实现（review-3 已记录，本轮浏览器复现确认仍在） |

## 三、口径分歧（非缺陷，沿前轮口径记录）

1. API 错误以异常（`CubeError.code` 带 `E_` 前缀）表达，非 PRD 字面 `{ok:false, error_code}` 返回值；语义一一对应（`E_CHALLENGE_NOT_STARTED`↔NOT_STARTED、`E_DEADLINE_EXCEEDED`↔TIMEOUT、`E_NOTATION_MALFORMED`↔INVALID_MOVE、`E_CHALLENGE_PAUSED`↔PAUSED、`E_CHALLENGE_ENDED`↔ALREADY_FINISHED 等）。
2. `rotateView` 实现签名为 `{up: FaceId, front: FaceId}`（视角状态对），非 PRD §5.3.4 的 `{axis, direction, steps}`；传非法参数抛 TypeError 而非错误码（健壮性小瑕疵，建议入参校验）。
3. `getChallengeResult(challengeId)` 必须传参（PRD 无参）；`getChallengeInfo().scramble` 恒 null（含结束后；题面打乱序列仅存于 PuzzleRecord 与 run 落盘记录）。
4. `MoveEvent` 指纹字段为 `from_fingerprint`/`to_fingerprint`（语义等价 PRD 13.4 的 `state_fingerprint_after`）；`applyMove` 返回为 AC-42 最小集的超集（多 op_id/deduplicated/next_observation/solved 等）。
5. 页面加载即自动生成题面进入 ready，无 §2.2 步骤 1 的 configuring 空态引导——符合 v1.9"配置常驻左栏、改动即重建"的演化方向，旧文表述未同步。
