## 二、修复的 1 个问题

**暂停期间右栏「观察数据」面板仍显示全部六面颜色（违反 PRD §7.2.1 P7'）**

- 现象：暂停后 3D 场景正确切遮蔽材质、`observe()` 正确返回 `E_CHALLENGE_PAUSED`，但 `observationView()` 只对 `ready/idle` 锁定，`paused` 态继续调 `peekObservation()` 投影——右栏 60 格彩色展开图照常渲染。玩家可以暂停后无限端详完整题面，正是 P7' 明确要堵死的「把暂停当无限观察用」；3D 遮罩因此形同虚设。
- 修复：`src/wiring/index.ts` `observationView()` 对 `paused` 返回锁定视图；`ObservationView` 增加 `lockReason`（`not-started` / `paused`），观察面板按原因显示不同锁定文案（暂停态：「挑战已暂停，计时已冻结，观察暂不可用；继续挑战后恢复。」）。恢复挑战后面板自动回到正常投影。
- 验证：新增 `tests/ui/observation-panel.test.ts` 4 条（含锁定↔渲染来回切换）；浏览器复验暂停 0 色格 / 恢复 60 色格。修复后 typecheck 0 错、217 测试全绿。
